YouTube Playlist Sorter Personal tool

A local desktop script that automatically sorts a single YouTube playlist by video duration.

Privacy policy Terms of service YouTube & Google data

Overview

YouTube Playlist Sorter is a private Python script that runs on a single user’s Windows computer. It uses the YouTube Data API to read the videos in one playlist on that user’s own channel and then updates the ordering of that playlist based on each video’s duration.

This tool is not a public website, mobile app, or commercial service. It is used only by the owner of the YouTube account that authorises it.

YouTube Data API usage

This tool uses the YouTube Data API (v3) only for the following operations:

• Reading playlist items from one specified playlist (video IDs, titles, and durations).
• Updating the position of playlist items in that playlist so that shorter videos appear first.

The tool does not upload videos, does not post comments, and does not access data from any other YouTube channels or playlists.

Privacy policy

Data accessed from YouTube

When you authorise the script with your Google account, it can access the following YouTube data for the authorised account:

• Playlist item metadata for the selected playlist (video ID, title, current position, duration).
• Your internal YouTube account identifier needed by the YouTube Data API to apply the changes.

How data is used

The script uses this data only to:

• Calculate the length of each video in the playlist.
• Sort the playlist items by duration.
• Send update requests to YouTube to change the playlist item positions accordingly.

The script does not profile users, perform analytics beyond ordering, or use the data for advertising or marketing purposes.

Data storage and sharing

• OAuth access and refresh tokens are stored locally on the user’s own computer in a file such as token.json.
• No YouTube data or tokens are transmitted to, or stored on, any third party server.
• No data is shared with any third party organisation or individual.

Data retention and deletion

• The only persistent data created by the tool is the local OAuth token file on the user’s device and an optional local log file of operations.
• To delete this data, the user can delete the token file and log file from their computer at any time.
• The user can also revoke the script’s access to their account from the Google Account security page (“Third-party access” section).

Revoking access and deleting local files removes the tool’s ability to read or modify any YouTube data.
