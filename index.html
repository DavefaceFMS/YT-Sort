YT Sort – Privacy & Quota Use

This page explains how the YT Sort tool uses your data and YouTube API Services.

Use of YouTube API Services

YT Sort connects to the YouTube Data API to read information about your playlists and videos so that they can be sorted according to the options you choose.

This application does not upload videos, modify video content, or post comments on your behalf. It only reads the metadata that is needed to show and sort your playlists.

By using this tool, you agree to be bound by the YouTube Terms of Service and the Google Privacy Policy .

Data access and storage

When you authorise access, YT Sort can view your YouTube account’s playlists and associated video metadata (such as title, ID, duration, and statistics), as permitted by the scopes you approve in the Google consent screen.

  • No YouTube account credentials (such as your password) are ever seen or stored by this tool.
  • Access tokens provided by Google are only used to make the authorised API requests.
  • No personal data from your YouTube account is sold, shared, or used for advertising.

Logs may record technical information (such as error messages or request counts) to help troubleshoot problems and understand quota usage. These logs are not used to build profiles of users.

Revoking access

You can revoke this application’s access to your YouTube account at any time from your Google Account settings:

  • Go to https://myaccount.google.com/permissions .
  • Find the entry for this application and remove its access.

Quota usage

YT Sort uses YouTube Data API quota only to:

  • Fetch playlist details and items in the selected playlists.
  • Retrieve video statistics or metadata required to sort and display results.

The application is designed to minimise API calls (for example by reusing data instead of repeatedly requesting the same playlist) so that quota usage is efficient.

Contact

If you have questions about how this tool uses YouTube API Services, your data, or API quota, please contact the developer using the details provided in the project’s repository on GitHub.
