YT Sort

YT Sort is a personal tool that helps you read and sort your YouTube playlists using the YouTube Data API.

What YT Sort does

When you authorise access with your Google account, YT Sort reads information about your playlists and videos (such as titles, IDs, durations, and statistics) so that it can display and sort them according to the options you choose.

The tool is read‑only: it does not upload videos, edit video details, or post comments on your behalf.

Use of YouTube API Services

This application uses YouTube API Services. By using YT Sort, you agree that your use of YouTube is governed by:

  • The YouTube Terms of Service .
  • The Google Privacy Policy .

More details about how YT Sort accesses, uses, stores, and deletes data from YouTube API Services are provided in the Privacy Policy.

Quota usage

YT Sort uses YouTube Data API quota only to:

  • Fetch your playlist details and the items in those playlists.
  • Retrieve video metadata or statistics needed to perform sorting.

The tool is designed to minimise repeated or unnecessary API calls in order to use quota efficiently.

Revoking access and more information

You can revoke this application’s access to your YouTube account at any time from your Google Account permissions page: https://myaccount.google.com/permissions .
